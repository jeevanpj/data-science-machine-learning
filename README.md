# Data Science & Machine Learning

A practical, continuously updated collection of my work in **Python, data analysis, statistics, and machine learning**. This repository documents my learning through hands-on exercises, small projects, experiments, and selected end-to-end implementations.

> My focus is on writing understandable code, explaining the reasoning behind each analysis, evaluating models correctly, and turning useful projects into reproducible applications.

## Areas of Focus

- **Python:** core programming, functions, data structures, and problem-solving
- **Data Analysis:** NumPy, Pandas, data cleaning, and exploratory data analysis
- **Visualization:** Matplotlib and Seaborn
- **Statistics:** descriptive statistics, probability, and statistical reasoning
- **Machine Learning:** regression, classification, model evaluation, and feature engineering
- **Deployment:** Streamlit and practical ways to make models accessible

## How to Explore

1. Open a project folder or notebook.
2. Read its introduction, problem statement, and methodology.
3. Review the analysis, code, and evaluation.
4. Follow the project-specific instructions to reproduce the work.

For projects that require packages, install the dependencies listed in that project's `requirements.txt`.

## Quality Principles

- Explain the problem and objective before presenting code.
- Keep notebooks organized and runnable from top to bottom.
- Separate exploratory work from reusable application code where practical.
- Report metrics honestly and explain what they mean.
- Do not commit credentials, private data, or large generated files.
- Include sources and dataset licenses where applicable.
